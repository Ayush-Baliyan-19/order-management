# Order Management System

A Java Spring Boot project focused on building a **highly extensible Order Management System** using clean code, modular design, and object-oriented design principles.

## 🎯 Aim

Build an order management system that can evolve to support new features such as pricing strategies, discounts, payment providers, and order lifecycle workflows with minimal changes to existing code.

This project also serves as a practical way to implement and understand design patterns from *Head First Design Patterns* in real-world backend development.

## 🧩 Key Principles

- **Extensibility:** Add new features with minimal changes to existing logic.
- **Loose Coupling:** Depend on abstractions rather than concrete implementations.
- **Composition over Inheritance:** Build flexible behavior using composable components.
- **Clean Architecture:** Separate business logic from API and infrastructure concerns.
- **Practical Design Patterns:** Apply patterns when they solve real problems.

## 🛠️ Tech Stack

- Java
- Spring Boot
- MySQL
- Gradle

## 📚 Design Patterns

Explore patterns such as Strategy, Observer, Decorator, Factory, Abstract Factory, Adapter, and State as the system evolves.

---

**Philosophy:** Build simple, understand the design challenges, and make the system extensible as requirements grow.
